# 盤面の意味論

## 座標と升目

盤面は 9 × 9 の 81 升です。
`Square` の raw 値は `file_index * 9 + rank_index` の file-major 順で、index は 0 から始まります。
USI 座標は筋に `1`–`9`、段に `a`–`i` を使います。

`Bitboard` は盤上 81 升だけを集合として表し、盤外 bit を結果に含めません。
`Bitboard::between(from, to)` は二つの端点が同じ筋、段、斜線上にある場合だけ、端点を除く間の升を返します。
同一升、隣接升、一直線でない二升では空です。
`Bitboard::line(from, to)` は一直線上にある二升を通る盤内の線全体を返します。

`Bitboard::is_aligned(from, to, king)` は、二升が玉から見て同じ向きの ray 上にあるかを判定します。
三点が一直線でも、玉が二升の間にある場合は `false` です。
これは pin された駒が pin の線上を動けるかを判定する意味論です。

## 利き

歩、桂、銀、金、玉の利きは手番の向きを含む通常の将棋規則に従います。
香、角、飛の直線利きは最初の占有升を含み、その先を含みません。
始点自身の占有状態は結果を変えません。
馬と龍は対応する大駒の直線利きに一歩の利きを加えます。

scalar build と AVX2 build は同じ升集合を返します。
どちらの実装が選ばれたかや内部の table layout は公開契約ではありません。

## 指し手

通常の盤上移動、成り、駒打ちに加え、`Move` と `Move32` は `none`、null、`resign`、`win`、`end` の特殊値を持ちます。
USI `0000` と `null` は同じ null move へ解析され、正規出力は `null` です。

`Move32` は移動する駒と捕獲駒の metadata を持てます。
局面から `Position::move32_from_move` を使って構築した完全な `Move32` は、CSA や KI2 の整形、探索の差分更新に利用できます。
USI 文字列だけから作った partial `Move32` には盤面由来の metadata がありません。

`Move` と `AperyMove` は同じ論理的な指し手を異なる raw layout で表します。
raw 値の互換性が必要な PACK などでは、必ず明示変換します。

## 合法手

完全な合法手の生成は、次をすべて満たします。

- 駒の動き、盤面占有、捕獲、成りの可否と強制成り。
- pin と自玉の安全。
- 王手中の玉移動、王手駒の捕獲、合駒。
- 二歩、行き所のない駒打ち、打ち歩詰めの禁止。

両王手では玉の手だけが回避手になり得ます。
歩と香は最終段、桂は最終 2 段へ不成で進めず、その升へ打つこともできません。

完全な集合には `LegalAll`、Rust の `generate_legal_all_move32`、Python の `Board.legal_moves()` / `legal_moves_move32()` を使います。
`Legal` は探索用に一部の任意不成を省略するため、表記変換、GUI の入力照合、perft には `LegalAll` を選びます。

`Captures`、`Quiets`、`Checks`、`QuietChecks`、`Evasions` などは探索を分割する sub-generator です。
`QuietChecks` は盤上の静かな王手だけでなく駒打ちの王手も含みます。
`Evasions` は pseudo-legal なので、後段で pin や玉の移動先を検査します。
非回避 mode は、局面が王手中でも自動的に回避手だけへ絞りません。

生成 API が保証するのは mode に属する手の集合であり、順序ではありません。
`Move` と `Move32` は、`Move32` の metadata を除けば同じ集合を返します。

## 一手詰め

`solve_mate_in_one` は次の条件を満たす手だけを返します。

1. 現局面で合法である。
2. 相手玉へ王手を与える。
3. 相手に合法な応手がない。

盤上の手、駒打ち、捕獲、成り、両方の手番を対象とし、玉の逃走、王手駒の捕獲、守備駒による捕獲、合駒を応手として検査します。
該当手がなければ `None`、複数あれば任意の一手を返します。

入力局面自体が不正なら、先に validation API で拒否してください。
特に手番側が自玉を王手にさらした局面は、通常の対局遷移として扱いません。

## 表記

KIF と KI2 の `同` は直前の着手先を参照します。
KI2 の正規出力は `同` の直後に全角スペースを一つ置きます。
右・左・直・上・寄・引などの曖昧性解消は、pin された候補も幾何学的候補として数えた上で決定します。
これにより、盤面表記としてどの駒を指すかが安定します。
